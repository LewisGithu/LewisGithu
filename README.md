### 📊 Projects I’ve Been Working On

* **📺 YouTube Channel Performance Engine ([Tableau Dashboard](https://github.com/LewisGithu/YouTube-API-Waigera-s-Channel-Analysis))**  
  An end-to-end data pipeline that extracts channel video metrics using the YouTube Data API. Unstructured video data is processed in Databricks, where a Google Gemini AI model automatically parses and classifies content categories and vehicle models, feeding into an [interactive Tableau dashboard](https://public.tableau.com/app/profile/lewis.githu1620/viz/WaigeraYouTubeChannelPerformance/Dashboard).

* **🪙 Crypto Trend Tracker ([CoinMarketCap API Pipeline](https://github.com/LewisGithu/CoinmarketAPI))**  
  I built an automated Python script that hooks directly into the CoinMarketCap API. It cleans up raw JSON data streams and drops them into clean Pandas DataFrames so anyone can track live crypto trends easily.

* **🏛️ Murang'a County Government Performance Project ([Databricks Work](https://github.com/LewisGithu/Murang-a-County-Government-Performance))**  
  An analysis of county government performance utilizing Databricks. I extracted data from the official county website and handled data transformations inside Databricks using SQL and Genie AI Workspace to build a visualized dashboard.

* **🌱 US Carbon Emissions Project ([Databricks Work](https://github.com/LewisGithu/Databricks-US-Emissions-Project))**  
  A deep-dive data analysis looking at carbon emissions across US states and counties. This project explores relationships between emissions data, population size, vehicle miles traveled, and regional electricity consumption.

* **🏠 Airbnb Analytics Dashboard ([Tableau Project](https://public.tableau.com/views/AirBNB2016DATA/Dashboard2?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link))**  
  Taking raw, multi-column Airbnb data and transforming it from chaotic rows into a clean, simplified, and highly interactive visual dashboard.

* **📋 Data Profession Dashboard ([Power BI Report](https://github.com/LewisGithu/Power-BI-Data-Profession-Dashboard))**  
  Curious about what data pros make around the world? I took raw survey data from 630 global entries, cleaned it up using Power Query, and built an interactive dashboard to show workplace demographics and pay trends.

* **🚲 Bike Store Sales Tracker ([Excel Data Product](https://github.com/LewisGithu/EXCEL-Bike-Sales-Project))**  
  An end-to-end spreadsheet tool built from scratch. I used Power Query to model retail data, making it simple to track major performance metrics and see exactly how customer demographics impact buying habits.
